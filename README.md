# E-Commerce Hybrid Automation Framework

## Tech Stack
Java | Selenium WebDriver | TestNG | Cucumber BDD | REST Assured | Jenkins | Maven

## Framework Architecture
- Page Object Model (POM)
- Data Driven Testing (TestNG DataProvider)
- BDD with Cucumber
- Extent Reports with Screenshot on Failure
- REST Assured API Validation
- Jenkins CI/CD Pipeline

## Project Structure
src/test/java/pages - Page classes
src/test/java/tests - Test classes
src/test/java/stepdefinitions - Cucumber step definitions
src/test/java/runners - Cucumber test runner
src/test/java/utils - Extent Reports, Listeners
src/test/resources/features - Feature files

## How to Run
mvn test
